# 照见古人 · 网页样板

在线体验：https://ling409762510-debug.github.io/zhaojian-guren/

手机或电脑浏览器直接打开，无需安装。

流程：首页 → 6道原创情境题 → 实际选择回顾 → 李清照示例报告 → 1080×1440收藏卡。

答案和进度只保存在当前浏览器；可返回修改、刷新继续、清空重做。收藏卡支持下载与图片预览，手机可长按保存。

## 样板边界

每个人均展示固定的李清照报告，6题用于体验交互，不计算人物匹配率。趣味自我探索，非专业心理测评。没有支付、兑换码、正式人物匹配库、账号或在线模型。不收集姓名和手机号。

## 源文件

index.html 为网页入口，style.css 为样式，data.js 为题目与报告，assets.js 为画像，app.js 为交互。使用 GitHub Pages 从 main 分支根目录发布。
